# Cloud Architect

**Category:** Specialisation Track - Nexora Institute of Computing

> **Status:** Scaffolded. See ROADMAP.md for the full route.

## Who this is for

Anyone who wants to design and operate large-scale cloud systems.

## What you will be able to do

- Design multi-region, highly available systems
- Automate infrastructure with IaC
- Operate Kubernetes and cloud-native platforms
- Reason about consensus and distributed storage
